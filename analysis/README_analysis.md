# Análisis de datos ATP

Cómo ejecutar el análisis y generar las gráficas:

1. Instalar dependencias (desde la raíz del proyecto):

```bash
pip install -r requirementes.txt
```

2. Ejecutar el script de análisis:

```bash
python3 analysis/analysis.py
```

Salida:
- `outputs/matches_per_year_surface.png` — gráfico apilado de partidos por año y superficie.
- `outputs/top10_winners.png` — gráfico de barras con los 10 jugadores con más victorias.
